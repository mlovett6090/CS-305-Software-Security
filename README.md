# CS-305-Software-Security
“Security-focused software project demonstrating vulnerability assessment, secure coding practices, and HTTPS implementation for Artemis Financial.”
Portfolio Reflection

Who was the client, and what issue did they want addressed? What did I do well, and why is secure coding important? Artemis Financial is a financial services company that required improved application security to protect sensitive customer data and financial transactions. The company’s primary need was to identify and remediate vulnerabilities while implementing secure communication protocols. I did well in identifying vulnerabilities using OWASP Dependency-Check and carefully analyzing the results to determine which issues required mitigation. Coding securely is important because it prevents data breaches, protects sensitive information, and ensures system integrity. Software security adds value to a company’s overall well-being by reducing risk, maintaining customer trust, and supporting compliance with industry standards. Which part of the vulnerability assessment was challenging or helpful? One of the most challenging yet helpful aspects was interpreting the vulnerability scan results and distinguishing between true vulnerabilities and false positives, which strengthened my analytical and decision-making skills.

How did I increase layers of security, and how will I assess vulnerabilities in the future? How did I ensure the software remained functional and secure? What tools and practices did I use, and what can I show employers? I increased layers of security by implementing HTTPS using SSL/TLS certificates, updating vulnerable dependencies, and applying secure coding practices such as input validation and proper configuration management. In the future, I would use a combination of tools such as SAST, DAST, and OWASP Dependency-Check to assess vulnerabilities and determine mitigation techniques. I ensured the application remained functional and secure by testing after each change and rerunning vulnerability scans to verify that issues were resolved without introducing new vulnerabilities. The tools and resources I used—including OWASP Dependency-Check, Java keytool, Maven, and secure coding principles—will be valuable in future assignments. From this assignment, I can show employers my ability to conduct vulnerability assessments, implement secure communication, remediate vulnerabilities, and apply industry-standard tools and practices in a real-world scenario.
